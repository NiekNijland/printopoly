# Bestelblad: {edition_name}

Print je niet zelf? Geef dit blad mee aan de kopieerwinkel. Per onderdeel staat op welk papier het moet en hoe het geprint wordt. Snijden, knippen en vouwen doe je zelf, met de instructies in deze set.

{if:copies_many}Aantal sets: {copies}. Kaarten en speelgeld hebben alle sets al in hun PDF, elke set met een eigen setteken: print die één keer. Bij de andere onderdelen staat het aantal per set en het totaal voor {copies} sets. Bij de uitnodiging staat het eigen aantal.

| Voor alle onderdelen |                                                                      |
| -------------------- | -------------------------------------------------------------------- |
| Kleur                | RGB (sRGB). Omzetten naar CMYK mag.                                  |
| Schalen              | Werkelijke grootte (100%). Nooit "passend maken".                    |
| Rand                 | Elk vel heeft een witte rand, dus printen tot de rand is niet nodig. |
