# Bestelblad: {edition_name}

Geef dit blad mee aan de drukkerij, of plak de regels in het bestelformulier. Per onderdeel staat wat er besteld wordt, op welke maat en hoe het gesneden wordt.

{if:copies_many}Aantal sets: {copies}. De aantallen hieronder zijn voor één set.

| Voor alle onderdelen |                                                                               |
| -------------------- | ----------------------------------------------------------------------------- |
| Kleur                | RGB (sRGB). Omzetten naar CMYK mag.                                           |
| Schalen              | Niet schalen, alles staat op werkelijke grootte.                              |
| Afloop               | 3 mm rondom, waar een onderdeel afloop heeft.                                 |
| Snijtekens           | Buiten de afloop, in de rand van de pagina.                                   |
| Snijkader            | Elke pagina met afloop heeft een TrimBox (eindmaat) en een BleedBox (afloop). |
