# Order sheet: {edition_name}

Not printing it yourself? Hand this sheet to the copy shop. For each part it says which paper to use and how to print it. Cutting and folding you do yourself, with the instructions in this set.

{if:copies_many}Number of sets: {copies}. The quantities below are for one set.

| For every part |                                                                       |
| -------------- | --------------------------------------------------------------------- |
| Colour         | RGB (sRGB). Converting to CMYK is fine.                               |
| Scaling        | Actual size (100%). Never "fit to page".                              |
| Margin         | Every sheet has a white margin, so borderless printing is not needed. |
