# monopoly-printset

Ontwerp een eigen editie van het bekende handelsspel en download print-klare PDF's met print-instructies: het bord als sticker voor een bestaande set, kaarten, eigendomsbewijzen en speelgeld als sticker of los.

> De naam van het spel is een merk van Hasbro. Dit is een privéproject; alles wat publiek wordt krijgt een eigen naam en vormgeving.
